# Описание данных (Olist E-commerce)

## 📌 Источник данных
В основе проекта лежит публичный датасет **Brazilian E-Commerce Public Dataset by Olist** (доступен на [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)). 
Это реальные анонимизированные данные о 100 тысячах заказов в бразильском маркетплейсе за 2016–2018 годы.

## 🚨 Важно: Где взять базу данных `olist.db`?
Так как итоговый файл базы данных SQLite (`olist.db`) весит более 25 МБ, я не могу загрузить его напрямую в этот репозиторий (ограничение GitHub).

**Как получить базу:**
1. Скачайте готовую базу `olist.db` по ссылке: [Яндекс.Диск](https://disk.yandex.ru/d/_ap7ymQ_AsmqVw)
2. Положите скачанный файл `olist.db` в эту папку (`data/`).

## 🛠 Как собрать базу самостоятельно (Альтернативный вариант)
Если вы хотите собрать базу с нуля:
1. Скачайте все 9 CSV-файлов с Kaggle.
2. Положите их в папку `data/`.
3. Запустите скрипт: `python import_data.py`.
Скрипт автоматически прочитает все CSV и создаст готовую базу `olist.db`.

## 📂 Структура базы данных (Таблицы)

При сборке базы из CSV-файлов Olist, я переименовала таблицы для удобства написания запросов (убрала префиксы `olist_..._dataset`). В файле `queries.sql` используются следующие названия:

*   `orders` — информация о заказах (статус, даты).
*   `order_items` — товары в заказах (цена, доставка).
*   `customers` — данные клиентов.
*   `products` — справочник товаров.
*   `sellers` — справочник продавцов.
*   `order_payments` — информация об оплатах.
*   `order_reviews` — отзывы клиентов.
*   `geolocation` — геолокация (индекс, координаты).
*   `product_category_name_translation` — перевод категорий (осталось без изменений, так как это справочник).
