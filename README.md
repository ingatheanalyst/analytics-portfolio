# Портфолио аналитика данных (Инга Кузнецова)

Работа с корпоративными данными, автоматизация бизнес-процессов и построение аналитической отчетности. 

Специализируюсь на извлечении инсайтов из «грязных» данных, построении витрин, продуктовых воронок и проверке гипотез. Имею опыт работы на стыке бизнеса и IT: от сбора требований до написания сложных SQL-запросов и визуализации в BI. 

**Стек:** SQL (PostgreSQL, SQLite), Python (Pandas, SciPy, Matplotlib, Seaborn), BI (Tableau, Yandex DataLens, Power BI), ETL.

---

## 📂 Мои проекты:

### 1. [Анализ данных кинологических соревнований (SQL/Data Analyst)](./sql-dog-project/)
*   **Задача:** Исследовать данные соревнований по IGP за 3 года, выявить закономерности в результатах пород.
*   **Стек:** SQL (SQLite), Python (Pandas), ETL.
*   **Что сделано:** Очистка данных (Data Cleaning), написание сложных запросов (JOIN, CTE, оконные функции), анализ динамики и корреляций. Оформление выводов и визуализация.
*   **Ключевой инсайт:** Выявлено смещение выборки (Selection Bias) при анализе пород, применен фильтр для корректной статистики.

### 2. [Продуктовая аналитика E-commerce (Product Analyst)](./ecommerce-product-analytics/)
*   **Задача:** Оценить конверсию пользователей на разных этапах, проверить эффективность новой фичи через A/B-тест, рассчитать Retention.
*   **Стек:** SQL, Python (SciPy, Pandas).
*   **Что сделано:** Построение воронки продаж, расчет статистической значимости (p-value), когортный анализ.
*   **Ключевой инсайт:** Выявлена самая слабая точка воронки (Корзина -> Покупка), доказана эффективность новой фичи (p-value < 0.05).

### 3. [Когортный анализ и юнит-экономика (Product Analyst)](./cohort-ltv-analysis/)
*   **Задача:** Оценить удержание пользователей (Retention), рассчитать LTV и окупаемость маркетинговых каналов (CAC/ROI).
*   **Стек:** Python (Pandas), SQL, Seaborn (Heatmap).
*   **Что сделано:** Построение когортной тепловой карты, расчет LTV по каналам, оценка юнит-экономики.
*   **Ключевой инсайт:** Канал `Referral` показывает лучшую окупаемость, в то время как `Paid Ads` работает в убыток. Даны рекомендации по перераспределению бюджета.

## 🎯 Мой подход
Я не просто строю графики, а ищу ответы на бизнес-вопросы. В каждом проекте есть блок **«Ключевые инсайты и бизнес-рекомендации»**, где я объясняю, какую проблему мы решали и какие выводы сделали на основе данных.
